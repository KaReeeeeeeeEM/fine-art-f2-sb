# Asset workflow

- The source PDF is the visual and content authority.
- Preserve extracted artwork, photographs, diagrams, decorative waves, panel frames, and captions inside this book directory.
- Do not use page-wide screenshot facsimiles as durable page output.
- Keep semantic text visible once. When a source crop already paints words, retain accessible/read-aloud semantics without double-painting.
- Preserve source crop, scale, orientation, labels, and z-order. Disable generic LLM cropping for this fixed-layout title; source-specific crop corrections must use ADT's versioned image paths.
- Record any generated/repaired asset, its source physical page, bounds, and affected output pages before accepting it.
